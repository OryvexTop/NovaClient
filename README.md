# OryvexClient – Modern Minecraft 1.8.9 Forge Cheat Client

## Features
- **20 Fully Working Modules** with custom settings (Range, Speed, etc.)
- **Right-Click Settings Panel**: Right-click any module in the ClickGUI to open a sleek settings panel with sliders, toggles, and keybinds.
- **Fixed Alt Manager**: Bulletproof reflection to bypass `final` modifiers for offline login.
- **Fixed Chat GUI**: Direct `inputField` access with beautiful dark-themed autocomplete suggestions.
- **Smooth Animations**: Sliding panels, smooth hover transitions, and accent lines.
- **Robust Config System**: Saves all custom module settings to JSON.

## Usage
- **Right Shift:** Open Click GUI
- **Right-click module in GUI:** Open Settings Panel
- **In chat, type `.`** to see command suggestions
- **Alt Manager:** Accessible from Main Menu

## Building Locally
```bash
./gradlew build
```
Output in `build/libs/`.
